🚀 GitHub Pages Deployment Guide

✅ Aplikasi PWA Anda siap untuk di-deploy ke GitHub Pages!
GitHub Pages menyediakan HTTPS gratis yang diperlukan untuk PWA.

📋 Langkah-langkah Deploy

1. Push ke GitHub Repository

Pastikan semua file sudah di-commit dan push ke GitHub:

git add .
git commit -m "Add PWA features"
git push origin main

2. Enable GitHub Pages

  1. Buka repository di GitHub
  2. Go to Settings tab
  3. Scroll ke bagian Pages
  4. Source: Deploy from a branch
  5. Branch: main
  6. Folder: / (root)
  7. Click Save

3. Generate URL GitHub Pages

Masukkan username dan repository name GitHub Anda:

⚠️ Penting! Setelah enable GitHub Pages, Anda perlu update beberapa path di kode untuk compatibility dengan GitHub Pages subdirectory.

4. Update Manifest.json

Update file manifest.json dengan path yang benar:

{
  "start_url": "/repository-name/",
  "scope": "/repository-name/",
  // ... rest of manifest
}

5. Update Service Worker

Update path di sw.js:

const STATIC_FILES = [
  '/repository-name/',
  '/repository-name/index.html',
  '/repository-name/alquran.html',
  // ... other files
];

6. Update HTML Files

Tambahkan base tag di semua HTML files (di dalam <head>):

<base href="/repository-name/">

✅ Checklist Deploy

  • Repository sudah di GitHub
  • GitHub Pages sudah enabled
  • manifest.json sudah diupdate
  • sw.js paths sudah diupdate
  • Base tag ditambahkan ke HTML
  • Icon sudah di-generate
  • Test PWA di localhost
  • Deploy dan test di GitHub Pages URL

📱 Testing Setelah Deploy

Tools untuk Testing:

  • Lighthouse - Chrome DevTools → Lighthouse tab
  • PWA Builder - pwabuilder.com
  • Web.dev - web.dev/measure
🎉 Setelah deploy, aplikasi Anda akan dapat diinstall di:
• Android: Chrome browser → Install app
• iOS: Safari → Share → Add to Home Screen
• Desktop: Chrome → Install button di address bar

🚨 Troubleshooting

Issues Umum:

  • 404 errors → Check base tag dan paths
  • Manifest tidak load → Check manifest path di HTML
  • Service Worker error → Check paths di sw.js
  • Icons tidak muncul → Check icon paths di manifest
