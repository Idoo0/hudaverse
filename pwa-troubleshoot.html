🔧 PWA Installation Troubleshoot

📋 PWA Requirements Check

🤖 Android (Chrome)

  1. Buka Chrome browser
  2. Go to: https://Idoo0.github.io/hudaverse/
  3. Tunggu loading lengkap
  4. Lihat address bar - ada ikon install
  5. Atau menu ⋮ → "Install app"
  6. Klik "Install"
Catatan: Fitur install hanya muncul jika semua PWA requirements terpenuhi.

🍎 iOS (Safari)

  1. Buka Safari browser
  2. Go to: https://Idoo0.github.io/hudaverse/
  3. Klik tombol Share (kotak dengan panah)
  4. Scroll dan pilih "Add to Home Screen"
  5. Edit nama jika perlu
  6. Klik "Add"
Catatan: iOS tidak show install prompt otomatis, harus manual via Share menu.

🖥️ Desktop (Chrome/Edge)

  1. Buka Chrome/Edge browser
  2. Go to: https://Idoo0.github.io/hudaverse/
  3. Lihat address bar - ada ikon install
  4. Atau menu → "Install HidayahPath"
  5. Klik "Install"

🌐 Live Tests

🚨 Common Issues & Solutions

❌ Install button tidak muncul

  • Check HTTPS: PWA hanya work di HTTPS
  • Check Manifest: File manifest.json harus accessible
  • Check Service Worker: SW harus registered successfully
  • Check Icons: Minimal perlu icon 192x192 dan 512x512
  • Wait for criteria: Browser butuh beberapa detik untuk evaluate

❌ Error saat install

  • Clear cache: Ctrl+Shift+R atau hard refresh
  • Check Console: F12 → Console untuk error messages
  • Try incognito: Test di private/incognito mode

❌ App tidak offline

  • Service Worker issue: Check SW registration
  • Cache strategy: Wait for initial cache completion
  • Network first visit: Visit app online first

🔍 Debug Tools

  • Chrome DevTools: F12 → Application → Manifest & Service Workers
  • Lighthouse: F12 → Lighthouse → Progressive Web App
  • PWA Builder: pwabuilder.com
  • Web.dev: web.dev/measure
